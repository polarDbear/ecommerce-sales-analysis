# ecommerce-sales-analysis
Python EDA project for e-commerce sales.

#项目介绍
本项目基于真实的电商交易数据（约13.8万条记录），利用 Python 进行探索性数据分析（EDA），从宏观经营趋势到微观用户行为，剖析销售额的多种影响因素，并为营销策略与物流定价提供数据支撑。

#使用工具
  Python 3.14
  Pandas, Numpy
  Matplotlib, Seaborn
  Jupyter Notebook

#主要分析内容
  1.整体经营情况：年度/月度销售额、利润与利润率趋势分析。
  2. 对比不同区域、不同销售渠道的贡献度与利润率。
  3.不同年龄段用户的消费力与客单价差异。
  4.折扣率分箱分析，寻找利润与销量的最优平衡点。
  5.运费区间对订单取消率的影响。

#核心业务分析与建议
  1.最优折扣区间：通过交叉分析发现，<11%-20% 的折扣率> 能同时兼顾高利润与高销量；当折扣率超过 51% 时，将面临亏损风险。建议      重点维持该折扣段，并避免长期进行高折扣活动。
  2.偏远地区运费痛点：运费在 60 元以内时订单取消率稳定在 6%，但当运费超过 90 元 时取消率显著上升。建议针对偏远地区<订单额度      达标即包邮>，一方面挖掘高运费地区（偏远地区）消费潜力，另一方便降低取消率。
  3.渠道发力点：移动端 APP 与网络商城贡献了主要销售额，且各渠道利润率无明显差异，说明促销活动全平台统一，建议后续针对社交媒      体渠道（目前占比最低）进行差异化营销。
  4.地区差异：南方地区销售额与利润最高，但利润率偏低；北方地区利润率最高但销售额低。建议针对南方地区优化折扣策略，在北方地区      加大拉新投入。

#如何运行本项目
  1. Clone 本仓库到本地。
  2. 确保已安装 `pandas`, `numpy`, `matplotlib`, `seaborn`, `jupyter`。
  3. 从 Kaggle 下载原始数据 并与 Notebook 放在同级目录。
  4. 打开终端运行：`jupyter notebook`，打开 `ecommerce_analysis.ipynb` 即可查看。
